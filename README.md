# Spam/Ham Email Classifier

Email classification workflow that builds a binary spam detector using text preprocessing, feature engineering, logistic regression, model evaluation, and prediction generation.

## Files
- `spam_ham_email_classifier.ipynb` — combined analysis and modeling notebook
- `spam_ham_email_classifier.py` — script version of the notebook code
- `requirements.txt` — Python dependencies inferred from the notebook

## Data
Place the following files in the project root before running the notebook:
- `train.csv`
- `test.csv`
- `spam_ham_data.zip` if using the zipped source workflow

## Notes
Generated outputs are intentionally excluded so the repository stays clean and reproducible.
